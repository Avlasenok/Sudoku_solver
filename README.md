# 🧩 Судоку Мастер (Sudoku Solver & Generator)

Адаптивное веб-приложение для генерации и решения судоку любой сложности. Проект построен на связке **Python (Flask)** для серверной математической логики и **JavaScript (Modern ES6+)** для отзывчивого интерактивного интерфейса.

---

## 🔥 Ключевые возможности

*   **🧠 Умный решатель (Backtracking):** Алгоритм поиска с возвратом на Python за миллисекунды находит решение для любой валидной головоломки.
*   **🎲 Динамический генератор:** Создание уникальных игровых полей прямо на бэкенде с выбором 3 уровней сложности (*Лёгкий, Средний, Сложный*).
*   **📱 Полная адаптивность (UX/UI):** Интерфейс на чистом CSS (Grid + Flexbox) идеально подстраивается под любые экраны — от мониторов ПК до дисплеев iPhone.
*   **🛡️ Защита от зависаний (Валидация «на лету»):** Скрипт мгновенно подсвечивает конфликтующие дубликаты в строках, столбцах и блоках 3х3, временно блокируя отправку невалидного поля на сервер.
*   **💾 Импорт из файлов (.txt):** Умный парсер загружает готовые паттерны судоку, записанные в файл одной строкой или матрицей 9х9 (поддерживает точки и дефисы вместо нулей).
*   **🔒 Фиксация подсказок:** Стартовые цифры защищены от случайного стирания с возможностью отключения блокировки через режим правки.
*   **🌐 Доступ по локальной сети:** Веб-приложение оптимизировано для запуска внутри домашней Wi-Fi сети для игры с мобильных устройств.

---

## 🛠️ Стек технологий

*   **Backend:** Python 3.x, Flask (Микрофреймворк)
*   **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, Media Queries), Vanilla JavaScript (AJAX / Fetch API)

---

## 🚀 Как запустить проект локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd Sudoku_solver
   ```

2. **Установите зависимости:**
   ```bash
   pip install flask
   ```

3. **Запустите веб-сервер:**
   Перейдите в папку бэкенда и запустите исполняемый файл:
   ```bash
   cd backend
   python app.py
   ```

4. **Откройте приложение:**
   Введите в адресной строке браузера: `http://127.0.0.1:5000`  
   *(Или используйте локальный IP-адрес вашего компьютера для игры со смартфона).*
